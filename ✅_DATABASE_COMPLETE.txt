   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co

2. IMPORT HELPER FUNCTIONS
   import { 
     sendMessage, 
     getConversationMessages,
     subscribeToMessages,
     followUser,
     searchUsers
   } from '@/lib/supabase/db-queries'

   // Send a message
   const msg = await sendMessage(conversationId, userId, 'Hello!')
   
   // Get messages
   const messages = await getConversationMessages(conversationId)
   
   // Real-time sync
   subscribeToMessages(conversationId, (newMsg) => updateUI(newMsg))

   await followUser(currentUserId, targetUserId)

🔐 SECURITY IMPLEMENTATION
═════════════════════════════════════════════════════════════════════════════

All tables have Row Level Security enabled:

users table
  ├─ SELECT: All users can view all profiles
  ├─ UPDATE: Users can only update their own
  └─ INSERT: Users can only insert their own

conversations table
  ├─ SELECT: Users can only see conversations they're in
  ├─ INSERT: Users can create conversations
  └─ UPDATE: Only creator can update

messages table
  ├─ SELECT: Only see messages in their conversations
  ├─ INSERT: Only send to conversations they're in
  ├─ UPDATE: Only modify their own messages
  └─ DELETE: Only delete their own messages

follows table
  ├─ SELECT: All follows are public
  ├─ INSERT: Users can only follow as themselves
  └─ DELETE: Users can only unfollow themselves

conversation_participants table
  ├─ SELECT: Users can only see their own participation
  └─ INSERT: Only conversation creator can add participants

attachments table
  └─ SELECT: Users can only see attachments in their conversations
